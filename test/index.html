🎬 TANMA! Subtitles (clone) — local test page

1. Pick any local video file (mp4/webm). Or it will try a sample clip from the web.

How to test
  1. Load the extension (see the project README) and make sure it's enabled.
  2. The floating toolbar should appear near the top of this page.
  3. Click the ⬆ import button on the toolbar and choose test/sample.ja.srt (Japanese), then press play.
  4. Japanese words get furigana; click a word for a definition and to mark it Known / Learning. Use the ☰ subtitle browser and ⚙ settings.
  5. Keys: A/D = prev/next line, S = replay line.

Tip: serve this folder over http (npx serve) so the content script runs, or enable “Allow access to file URLs” for the extension if opening via file://.
