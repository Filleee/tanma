Setup guide

Get TANMA! up and running

Follow these five parts in order. By the end you'll have the extension installed, a dictionary loaded, Anki wired up with the lapis-simplified note type, and your first mined card sitting in your deck.

🕒 ~20–30 min 🧩 Chrome / Edge / Brave 🎴 Anki (optional but recommended)

Part 1

Install the extension

Grab the pre-built release and load it unpacked — no building required.

You'll need: a Chromium browser (Chrome, Edge, or Brave). That's it.
1

Download the latest build

Grab the newest dist.zip from the releases page:

↓ Download the latest build

Then unzip it — you'll get a dist folder.

2

Load it unpacked

  1. Open chrome://extensions.
  2. Turn on Developer mode (top-right).
  3. Click Load unpacked and choose the unzipped dist folder.
3

Pin it

Click the puzzle-piece icon in the toolbar and pin TANMA! so its popup is one click away.

The popup's Dashboard & settings → Open button takes you to the options page, where the rest of this guide happens.

Prefer to build from source? Clone the repo and run npm install && npm run build in project/, then load project/dist.

Part 2

Add a dictionary

Look-ups need at least one dictionary. TANMA! uses the same Yomitan-format .zip dictionaries you may already know.

1

Open the dashboard

Popup → Dashboard & settings → Open, then go to the Dictionaries tab.

2

Install a dictionary

Two ways:

  • One-click catalog — pick from the built-in list (Jitendex, JMnedict, KANJIDIC, frequency & pitch dicts) and it downloads + imports for you.
  • Import a file — drop in any Yomitan .zip you've downloaded.
Start with Jitendex (a great free JMdict-based dictionary). Add a frequency and a pitch-accent dictionary later for richer cards.

Big dictionaries take a little while to import the first time — that's normal; it only happens once.

Now open any Japanese subtitle and click a word — you should see a definition. 🎉 If look-ups are all you wanted, you're done. For Anki, continue.

Part 3 · the important one

Set up Anki mining

TANMA! sends cards to Anki through the AnkiConnect add-on, using the lapis-simplified note type. Do these in order.

1

Install Anki

Download and install the desktop app from apps.ankiweb.net. Keep it open while you mine.

2

Install AnkiConnect

In Anki: Tools → Add-ons → Get Add-ons… and paste this add-on code:

2055492159

Click OK, then restart Anki.

3

Install the lapis-simplified note type

lapis-simplified is a clean mining note type (a simplified lapis). Install it once:

  1. Download the latest .apkg from the lapis-simplified releases.
  2. In Anki: File → Import and choose that .apkg.
  3. This adds the note type (and a sample card) to your collection.
TANMA! auto-selects a note type whose name contains “lapis”. If yours is named differently, you'll just pick it from the Note type dropdown in the dashboard (next steps). Check the repo's README for the current install steps.
4

Let TANMA! talk to Anki (CORS)

AnkiConnect only accepts requests from origins on its allow-list. Add the extension's origin:

  1. In the TANMA! dashboard → Anki mining, click Test connection. It prints your extension's exact origin, e.g.
    chrome-extension://<your-id>/
  2. In Anki: Tools → Add-ons → AnkiConnect → Config.
  3. Add that origin to webCorsOriginList:
{
  "webCorsOriginList": [
    "http://localhost",
    "chrome-extension://<your-id>"
  ]
}

Save, then restart Anki.

Use the real id the Test button showed — every unpacked extension has its own. Keep the trailing part exactly as printed.
5

Configure mining in the dashboard

Back in Dashboard → Anki mining:

  • Turn Enable Anki mining on.
  • Click Test connection — it should go green.
  • Pick your Deck (make one like “Mining” in Anki first) and Note type (lapis-simplified is auto-picked).
  • Choose what to capture: sentence audio, picture (still or animated), word audio, and your main definition dictionary.

Part 4 · optional

More subtitles & companions

Extra ways to get subtitles and text into TANMA!.

＋

Jimaku (anime subtitles)

Get a free API key from jimaku.cc/profile, paste it into Dashboard → Jimaku, and TANMA! can auto-find and load Japanese subs for the anime you're watching.

🚧 The tanma-asr and tanma-hook companions below are work in progress — coming soon. Here's what they'll do.
＋

tanma-asr — make subtitles from any media Coming soon

No subtitle file? Run the tanma-asr companion, drop your audio/video onto it, and it writes a timed .srt (kotoba-whisper) you can import. Great for clips with no subs available.

＋

tanma-hook — read visual novels & games Coming soon

Run tanma-hook, hook your game's text, and open TANMA!'s Reader page (popup → Game / VN reader). Lines stream in with the same look-up + mining pipeline, including voice + screenshot capture.

Part 5

Mine your first card

1

Open a video with subtitles

On YouTube, subtitles load automatically. Elsewhere, click ⬆ import on the in-page toolbar to load a .srt/.vtt/.ass, or search Jimaku.

2

Look up a word

Click a word, or hold Alt and hover to grab a word mid-sentence. Mark it Known or Learning to track your progress.

3

Mine it — now or later

  • Now: click ＋ in the look-up. The card lands in your deck with sentence audio, a screenshot, and the definition.
  • Later: click ⧉ to add it to the queue. Keep watching, then open the queue and hit Mine all → Anki — it runs muted so you can look away.
4

Check Anki

Open your deck in Anki — your new card is there, ready to review. You're mining! 🎴

Troubleshooting

If something's off

“Test connection” fails

Make sure Anki is open, AnkiConnect is installed (restart Anki after installing), and your extension origin is in webCorsOriginList (restart Anki after editing the config).

Clicking a word shows nothing

You need a dictionary — import one in Dashboard → Dictionaries (Part 2).

No subtitles appear

On YouTube, wait a moment or toggle CC; elsewhere, import a subtitle file or search Jimaku. You can nudge timing with the offset control.

The card has no picture/audio

Check the capture toggles in Anki mining, and confirm the note type has the matching fields (lapis-simplified does).
